# Design Brief

Use midnight navy, institutional slate, athletic teal, warm white, steel gray, amber for attention, and red only for restriction. The interface favors strong hierarchy, restrained typography, clear forms, compact data tables, and meaningful status labels. Public pages explain the system without fabricated outcomes. Confidential views emphasize authorization and readable record details. Responsive breakpoints collapse navigation and grids for mobile; print styles remove navigation and retain report content. All interactions use native HTML forms and server requests.
