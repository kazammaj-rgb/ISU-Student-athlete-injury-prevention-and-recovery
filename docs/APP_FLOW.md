# Application Flow

1. Public visitor reads Home/About/Help or opens Login/Register.
2. Athlete registration creates athlete-only credentials and profile.
3. Sign-in validates email, password, and one-time session arithmetic challenge.
4. Server redirects to a role-scoped dashboard.
5. Athlete submits a concern and views own case.
6. Clinician reviews a case and can document milestones, schedule follow-up, and record clearance.
7. Admin/clinician runs documentation readiness evaluation and reviews stored explanation.
8. Coach views roster-linked status without clinical notes.
9. Admin reviews aggregate report and activity log.
