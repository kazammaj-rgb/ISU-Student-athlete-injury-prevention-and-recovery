# User Manual and Evidence Checklist

## Athlete
Register with school email, student ID, sport, and a 12-character minimum password. Sign in with the arithmetic challenge. Dashboard → Recovery cases → submit a concise concern. Return to cases to see its status. Ask authorized staff about appointments and requested supporting information. Participation status is not granted by the documentation evaluator.

## Healthcare Personnel
Sign in with a provisioned clinician account. Open Recovery cases, expand Manage case, start review, add dated follow-up, record milestones, and enter a clearance decision only when professionally authorized. Use Evaluate documentation readiness to see missing/present administrative items. Preserve professional judgment and institutional process.

## Coach
Open Recovery cases to see cases for currently rostered athletes, their workflow status, and a limited clearance indicator. Clinical concern text and detailed notes are withheld.

## Administrator
Use the operational dashboard, activity log, and printable summary. Admin role does not grant clinical note or clearance editing permission in this implementation. User/sport/team CRUD and backup/restore controls are not yet implemented.

## Screenshot Checklist (do not fabricate)
Capture login with challenge; role dashboard; athlete concern form and submitted case; clinician review/milestone/follow-up/clearance forms; DSS result and explanation; coach-limited roster view; print summary; audit log. Use only fictional seed accounts. Hide credentials and sensitive browser data.
